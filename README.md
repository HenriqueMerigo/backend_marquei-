# ⚙️ Marquei — API & Backend

API e motor de regras de negócio para o **Marquei**, ERP voltado para barbearias, salões de beleza e serviços estéticos.

## 🛠️ Tecnologias
- **Linguagem:** Python
- **Framework:** Flask / FastAPI
- **Banco de Dados:** SQLite / MongoDB / Redis

## 🚀 Funcionalidades
- Gerenciamento de agendamentos (suporte a múltiplos produtos e serviços por atendimento).
- Cadastro de clientes, profissionais e controle de catálogo.
- Módulo de estoque e fluxo financeiro.
- Integrações (Google Calendar, automações via n8n / WhatsApp).

## ▶️ Iniciar servidor Flask
Na pasta `backend_marquei-`, execute:

```     bash python main.py     ```

O servidor será iniciado na porta `5000`.
